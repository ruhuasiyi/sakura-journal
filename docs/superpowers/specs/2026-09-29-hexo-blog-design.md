# Hexo 二次元博客设计方案

日期：2026-09-29
状态：待用户确认

## 1. 目标

搭建一个二次元（淡粉手帐风）个人博客，主题从零生成、由 AI 辅助编写和后续调整，零托管费用。

## 2. 已确定的技术决策

| 决策项 | 结论 |
|--------|------|
| 静态 vs 动态 | 静态（Hexo） |
| 主题来源 | 从零生成，放 `themes/` 下与内容同仓库 |
| 模板引擎 | EJS（Hexo 原生渲染，无额外构建链） |
| 样式方案 | 原生 CSS + CSS 变量设计令牌，不用 Tailwind/SCSS |
| 脚本 | 原生 JS，无打包器 |
| 评论 | giscus（数据存 GitHub Discussions） |
| 代码托管 | GitHub（仓库名任意，暂定 `blog`） |
| 部署 | Cloudflare Pages，`git push` 自动构建发布，先用免费 `*.pages.dev` 域名 |
| 看板娘 | 开源 live2d-widget + 经典开源模型占位，后续可换 |

## 3. 待定项（不阻塞开发）

- **博客名称/作者名**：未定。开发期统一用占位符「pinkblog」，仅在 `_config.yml` 和主题 `_config.yml` 中出现，确定后一处改完。
- **自定义域名**：暂无，后续在 Cloudflare Pages 后台加即可，不影响代码。
- **看板娘角色**：先用开源经典模型，后续可整体替换。

## 4. 视觉设计：C1 · 淡粉手帐

设计方向已经过三方案视觉稿对比确认：以「和风手帐（journal）」为骨架，樱花粉仅作点缀——纸感为主，粉色画龙点睛。

### 4.1 设计令牌（CSS 变量）

| 令牌 | 亮色 | 暗色（夜手帐） |
|------|------|------|
| `--color-bg` | `#FDF6F4` | `#2A2226` |
| `--color-card` | `#FFFCFB` | `#332A2E` |
| `--color-primary`（印章红粉） | `#C4536B` | `#E08198` |
| `--color-accent` | `#B96A85` | `#C990A4` |
| `--color-text` | `#6B5450` | `#EADDD8` |
| `--color-border` | `#F0DEDA` | `#453A40` |
| 圆角 | 6px（纸片感，非大圆角） | 同 |
| 阴影 | `2px 3px 0 rgba(180,120,130,.10)`（硬偏移，非光晕） | 同（更深） |

暗色实现：`<html data-theme="dark">` 切换同一组变量的值，组件样式不写两份。

### 4.2 手帐质感元素

- 页面底纹：极淡的横线（信纸格线）
- 卡片：白纸片 + 虚线边框分隔 + 顶部和纸胶带（半透明粉色斜条）
- 印章元素：标签、NEW 徽章用印章样式（实底 + 微旋转）
- 卡片微歪斜（±1°），标题带手写感斜杠前缀 `/`
- 分隔线用虚线（`dashed`），导航底部同理
- 少量樱花瓣散落（静态点缀，动态飘落见特效模块）

### 4.3 字体

霞鹜文楷屏幕版（LXGW WenKai Screen），通过 CDN 引入——手写感与手帐风天然契合；系统字体兜底。

## 5. 页面清单（9 类）

| 页面 | 布局要点 |
|------|----------|
| 首页 | 桌面：文章卡片流 + 右边栏（自我介绍卡/标签云/最近文章）；手机：单栏，边栏沉底 |
| 文章页 | 正文单栏限宽；右侧悬浮 TOC；文末 giscus |
| 归档 | 按年份分组的文章列表（手帐目录式） |
| 标签 / 分类 | 聚合页 + 单个标签/分类下的文章列表 |
| 关于 | 单页 |
| 友链 | 卡片列表（头像 + 名字 + 描述），数据在主题配置维护 |
| 项目/相册 | 卡片网格（封面图 + 简介），可带手帐贴纸感 |
| 404 | 手帐风趣味页（如「这一页被撕掉了」） |

响应式断点：移动端优先，≥768px 显示边栏/侧栏。

## 6. 特效模块（各自独立，主题配置中可开关）

| 模块 | 文件 | 说明 |
|------|------|------|
| 樱花飘落 | `sakura.js` | Canvas 实现；遵循 `prefers-reduced-motion`；移动端减少花瓣数量 |
| 看板娘 | `live2d.js` | 基于 stevenjoezhang/live2d-widget，右下角，可配置模型 |
| 暗色切换 | `darkmode.js` | 手动切换存 localStorage；首次访问跟随系统偏好 |

文章目录、图片懒加载等基础功能不依赖特效开关，始终可用。

## 7. 代码结构

```
blog/
├── _config.yml            # 站点配置（站名、作者、URL、分页）
├── _config.pinkblog.yml   # 主题配置覆盖（特效开关、友链、看板娘）
├── source/
│   ├── _posts/            # 文章 Markdown
│   ├── about/ links/ projects/   # 单页
│   └── 404.html
└── themes/pinkblog/
    ├── _config.yml        # 主题默认配置
    ├── layout/            # EJS 模板（layout/ index/ post/ page/ archive/ 等）
    └── source/
        ├── css/           # tokens.css + base.css + 各组件样式
        └── js/            # sakura.js / live2d.js / darkmode.js / toc.js
```

原则：内容（`source/`）与视觉（`themes/`）分离，后续调主题只动 `themes/pinkblog/`；用户可配置项（特效开关、友链数据）走主题配置文件，不改代码。

主题代号「pinkblog」与站名占位符同名，站名确定后不冲突（站名只是配置值）。

## 8. 写作与部署工作流

- 写作：`hexo new post "标题"` → 编辑 `source/_posts/*.md` → `git push`
- 部署：Cloudflare Pages 连接 GitHub 仓库，构建命令 `npx hexo generate`，产物目录 `public/`，推送后自动发布
- 本地预览：`hexo server`（http://localhost:4000）

## 9. 错误与边界处理

- 图片懒加载（`loading="lazy"`），防止相册/长文首屏卡顿
- giscus 未配置时文章页不渲染评论区，不报错
- 看板娘模型 CDN 加载失败时静默降级（不显示，不影响页面）
- 暗色模式下樱花特效降低不透明度；和纸胶带/印章配色随暗色令牌整体切换

## 10. 验收标准
