# Hexo 二次元博客 Demo 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 搭建一个本地可预览的 Hexo 博客 demo，包含从零生成的「C1 淡粉手帐」主题（9 类页面 + 3 个特效模块）。

**Architecture:** Hexo 静态站点，主题 `themes/pinkblog` 与内容同仓库。EJS 模板 + 原生 CSS（设计令牌）+ 原生 JS，无任何额外构建链。内容在 `source/`，视觉在 `themes/pinkblog/`。

**Tech Stack:** Hexo（最新版）、hexo-renderer-ejs、hexo-renderer-marked、hexo-generator-index/archive/tag/category、hexo-server。Node 24。

**Spec:** `docs/superpowers/specs/2026-09-29-hexo-blog-design.md`（本计划与 spec 一起阅读）

**Demo 范围之外**（后续计划）：GitHub 推送、Cloudflare Pages 部署、giscus 激活、自定义域名。

## Global Constraints

- 站名/作者占位符：站名 `pinkblog`，作者 `RHSY`（站名后续只在 `_config.yml` 改一处）
- 主题名固定为 `pinkblog`，所有代码不做其它命名
- 模板引擎只用 EJS；样式只用原生 CSS（无 Tailwind/SCSS/Stylus）；脚本只用原生 JS（无打包器）
- 设计令牌（亮色）：`--color-bg: #FDF6F4`、`--color-card: #FFFCFB`、`--color-primary: #C4536B`、`--color-accent: #B96A85`、`--color-text: #6B5450`、`--color-text-soft: #B39A94`、`--color-border: #F0DEDA`、圆角 6px、阴影 `2px 3px 0 rgba(180,120,130,.10)`
- 设计令牌（暗色「夜手帐」）：`--color-bg: #2A2226`、`--color-card: #332A2E`、`--color-primary: #E08198`、`--color-accent: #C990A4`、`--color-text: #EADDD8`、`--color-text-soft: #A08B90`、`--color-border: #453A40`
- 手帐质感必备元素：信纸横线底纹、卡片和纸胶带、印章式标签、卡片微歪斜（±1° 内）、虚线分隔
- 字体：`LXGW WenKai Screen`（jsDelivr CDN）+ 系统字体兜底
- 特效开关在 `themes/pinkblog/_config.yml`：`effects.sakura`、`live2d.enable`
- 遵循 `prefers-reduced-motion`：樱花与看板娘在该设置下不加载
- 每个任务结束必须 `npx hexo clean && npx hexo generate` 通过且检查点 grep 通过后才能 commit

```js
(function () {
  if (matchMedia('(prefers-reduced-motion: reduce)').matches) return;
  var canvas = document.createElement('canvas');
  canvas.id = 'sakura-canvas';
  document.body.appendChild(canvas);
  var ctx = canvas.getContext('2d');
  var W, H, petals = [];

  function resize() { W = canvas.width = innerWidth; H = canvas.height = innerHeight; }
  function isDark() { return document.documentElement.dataset.theme === 'dark'; }
  function petalCount() { return innerWidth < 768 ? 12 : 26; }

  function Petal() { this.reset(true); }
  Petal.prototype.reset = function (init) {
    this.x = Math.random() * W;
    this.y = init ? Math.random() * H : -20;
    this.size = 6 + Math.random() * 8;
    this.speedY = .6 + Math.random() * 1.2;
    this.rot = Math.random() * Math.PI * 2;
    this.rotSpeed = (Math.random() - .5) * .04;
    this.flip = Math.random() * Math.PI * 2;
    this.flipSpeed = .02 + Math.random() * .04;
  };

  function tick() {
    ctx.clearRect(0, 0, W, H);
    ctx.fillStyle = isDark() ? '#E08198' : '#F4A7B9';
    ctx.globalAlpha = isDark() ? .3 : .5;
    for (var i = 0; i < petals.length; i++) {
      var p = petals[i];
      p.y += p.speedY;
      p.x += Math.sin(p.y / 40) * .6;
      p.rot += p.rotSpeed;
      p.flip += p.flipSpeed;
      if (p.y > H + 20) p.reset(false);
      ctx.save();
      ctx.translate(p.x, p.y);
      ctx.rotate(p.rot);
      ctx.scale(Math.sin(p.flip), 1);
      ctx.beginPath();
      ctx.moveTo(0, 0);
      ctx.bezierCurveTo(p.size, -p.size, p.size * 1.6, p.size * .6, 0, p.size);
      ctx.bezierCurveTo(-p.size * 1.6, p.size * .6, -p.size, -p.size, 0, 0);
      ctx.fill();
      ctx.restore();
    }
    requestAnimationFrame(tick);
  }

  resize();
  addEventListener('resize', resize);
  for (var i = 0; i < petalCount(); i++) petals.push(new Petal());
  tick();
})();
```
